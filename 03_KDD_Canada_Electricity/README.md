# Project 3: KDD · Is Canada's Grid Becoming Less Combustion-Dependent?

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/anita-agasaveeran/Assignment4/blob/main/03_KDD_Canada_Electricity/notebooks/KDD_Canada_Electricity.ipynb)

**Problem:** use 18 years of monthly Statistics Canada electricity data to find which provinces behave alike, when their power systems changed, which months were anomalous, and whether availability can be forecast better than a seasonal-naive benchmark.

**Methodology:** the KDD process (Fayyad et al., 1996): goals → selection → preprocessing → transformation → data mining → interpretation/evaluation → using the knowledge. A front pass (data checks, frozen holdouts) comes first.

**Data:** StatCan tables 25-10-0015-01 and 25-10-0016-01 via [Kaggle](https://www.kaggle.com/datasets/hgultekin/canada-monthly-electricity-benchmark) (Statistics Canada Open Licence). See [`data/README.md`](data/README.md).
